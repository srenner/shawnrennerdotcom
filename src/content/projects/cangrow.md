My latest project is an automated indoor gardening system I call CANgrow. CAN-bus 
enabled microcontroller nodes are chained together to a Raspberry Pi central hub 
and automate tasks for light and water management in your indoor garden.

The project is currently in active development, and I hope to have a demo soon. 
When the code is ready for release, I will also compile a complete list of parts 
so people can build their own. You can check out the repo 
[on my GitHub](https://github.com/srenner/cangrow).
